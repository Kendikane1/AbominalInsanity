## Section 1: Project Overview

**What we are building**: A Generalised Zero-Shot Learning (GZSL) system that classifies visual object categories from EEG (electroencephalography) brain signals — including categories that were *never seen during training*. The system uses synthetic training data generated by a conditional WGAN-GP to fill in the missing unseen classes.

**Dataset**: BraVL / ThingsEEG-Text
- 1654 *seen* object categories: 10 EEG trials each → 16,540 brain recordings total
- 200 *unseen* object categories: 80 EEG trials each → 16,000 brain recordings total (test-only, never used in training)
- EEG features: 561-dimensional = 17 EEG channels × 33 time points (70–400ms post-stimulus, ~100Hz)
- Visual features: CORnet-S model applied to object images, projected down to 1000-D via PCA (all 1000 components kept)
- Labels: seen classes 1–1654, unseen classes 1655–1854

**Core metric**:
```
H = 2 · AccS · AccU / (AccS + AccU)   (harmonic mean)
```
H penalises any classifier that routes all predictions to seen or all to unseen. You need *both* AccS and AccU to be good simultaneously. Current best: **H=4.77%, AccS=4.11%, AccU=5.69%**.

**Why it's hard**: Random chance per class is ~0.054% (1 out of 1854 classes). We achieve ~76× chance on seen and ~11× chance on unseen. The fundamental difficulty is that EEG signals from 1654 different objects look nearly identical — the 561-D features have very weak class-discriminative information (encoder top-1 accuracy ~4%).

## Section 2: Pipeline — Mathematical Formulation

### 2.1 Brain Encoder f_b

```
f_b : R^{561} → S^{63}    [maps to the unit sphere in 64-dimensional space]

f_b(x) = L2_normalize( W_3 · LayerNorm(ReLU(W_2 · LayerNorm(ReLU(W_1 · x + b_1)) + b_2)) + b_3 )

Architecture: 561 → 1024 → 512 → 64
Each hidden layer: Linear → LayerNorm → ReLU → Dropout(0.1)
Output: L2-normalised → lies exactly on S^{63} (unit sphere in R^{64})

Optimal hyperparameters (validated via sweep):
  τ = 0.05   (InfoNCE temperature)
  epochs = 75
  lr = 2×10^{-3}  (AdamW, cosine schedule with 10% warmup)
  weight_decay = 1×10^{-4}
  batch_size = 256
```

The L2-normalisation forces all outputs onto the unit sphere. This is intentional: cosine similarity between unit vectors is just their inner product, which makes the InfoNCE loss well-defined and bounded.

### 2.2 Image Projector g_v

```
g_v : R^{1000} → S^{63}

g_v(v) = L2_normalize( W_2 · LayerNorm(ReLU(W_1 · v + b_1)) + b_2 )

Architecture: 1000 → 512 → 64
Trained jointly with f_b — same AdamW optimiser, same loss
```

### 2.3 InfoNCE Contrastive Loss (full)

Given a batch of N (brain, image) pairs {(x_i, v_i)}:

```
b_i = f_b(x_i),   e_i = g_v(v_i)   [both on S^{63}]
sim(a, b) = a · b   [dot product = cosine similarity for unit vectors]

L_brain→image = -(1/N) Σ_i  log [ exp(sim(b_i, e_i) / τ) / Σ_j exp(sim(b_i, e_j) / τ) ]

L_image→brain = -(1/N) Σ_i  log [ exp(sim(e_i, b_i) / τ) / Σ_j exp(sim(e_j, b_i) / τ) ]

L_total = (L_brain→image + L_image→brain) / 2
```

The temperature τ = 0.05 is small. This sharpens the softmax: the model is heavily penalised even for near-miss matches. It works here because image prototypes on S^{63} are nearly orthogonal to each other (mean cosine similarity ≈ 0.014 between different classes), so there is genuine signal in the small angular differences.

### 2.4 Image Prototypes

```
For each class c ∈ {1, ..., 1854}:
  s_c = L2_normalize( (1/n_c) · Σ_{i: y_i = c} g_v(v_i) )

S_seen   ∈ R^{1654 × 64}   [prototype matrix for seen classes]
S_unseen ∈ R^{200  × 64}   [prototype matrix for unseen classes]

Key property: mean pairwise cosine similarity between prototypes ≈ 0.014
  → prototypes are nearly orthogonal (well-separated in embedding space)
  → consequence of L2-normalisation in 64-D: see concentration of measure
```

Unseen prototypes are computed using image embeddings only (no brain data leaks in). This is the *only* information the generator receives about unseen classes during synthesis.

### 2.5 Conditional WGAN-GP

**Generator**:
```
G : R^{100} × R^{64} → S^{63}

Input: noise z ~ N(0, I_{100}),  prototype s_c ∈ R^{64}
Concatenate: [z ; s_c] ∈ R^{164}
Layers: 164 → 256 → 256 → 64  (LeakyReLU activations, no normalisation)
Output: L2_normalize( · ) → on S^{63}

Samples ê_{c,k} = G(z_k, s_c),  k = 1,...,20  per class c
```

**Critic**:
```
D : R^{64} × R^{64} → R

Input: embedding e ∈ R^{64},  prototype s_c ∈ R^{64}
Concatenate: [e ; s_c] ∈ R^{128}
Layers: 128 → 256 → 256 → 1  (LeakyReLU, no normalisation)
Output: scalar score (no sigmoid — Wasserstein critic, not a probability)
```

**Training objective**:
```
Critic loss:
  L_D = E_{z,c}[ D(G(z,s_c), s_c) ]  -  E_{e~P_real, c}[ D(e, s_c) ]  +  λ · GP

Generator loss (updated every n_critic=5 critic steps):
  L_G = -E_{z,c}[ D(G(z,s_c), s_c) ]

Gradient penalty:
  ê = α · e_real + (1-α) · G(z, s_c),   α ~ Uniform(0,1)
  GP = E[ ( ||∇_ê D(ê, s_c)||_2 - 1 )^2 ]

Hyperparameters: λ=10, n_critic=5, lr=1×10^{-4}, β=(0.0, 0.9), steps=10,000
```

The gradient penalty enforces that the critic's gradient norm ≈ 1 at interpolated points between real and fake samples. This implements the 1-Lipschitz constraint: |D(a) - D(b)| ≤ ||a - b||_2 for all a, b.

### 2.6 GZSL Classifier

```
Training data:
  - Real seen embeddings:     E_train_seen  ∈ R^{13232 × 64}  (1654 classes, ~8/class)
  - Synthetic unseen:         E_synth       ∈ R^{4000 × 64}   (200 classes, 20/class)
    → Downsampled to ~8/class to match seen density → ~1600 synth samples used
  - Combined training set: ~14,832 samples, 1854 classes

Model: Multinomial Logistic Regression with class_weight='balanced'
  θ = argmin  Σ_{(e,y)} -log P(y | e; W, b)
  P(y=c | e) = softmax(W_c · e + b_c)
  W ∈ R^{1854 × 64},  b ∈ R^{1854}

Evaluation:
  Classify: E_test_seen (3308 samples) + E_unseen (16,000 samples)
  AccS = accuracy on E_test_seen (1654 seen classes)
  AccU = accuracy on E_unseen    (200 unseen classes)
  H = 2 · AccS · AccU / (AccS + AccU)
```

## Section 3: Completed Experiments and Findings

### 3.1 Phase E — Encoder Optimisation (COMPLETE)
Systematic sweep of encoder hyperparameters (embed_dim, τ, lr, architecture). Best: embed_dim=128, τ=0.15, lr=1×10^{-3}, LayerNorm, cosine warmup. Encoder top-1: 1.90% → 2.87% (+51%). H-mean: 0.42% → 0.70% (+67%).

### 3.2 Image Alignment Paradigm Shift (COMPLETE)
Switched alignment target from EEG→text embeddings to EEG→image embeddings (CORnet-S). This was the single biggest improvement in the project. H-mean: 0.58% → 4.53% (+681%). AccU: 0.32% → 5.73% (+17×). Reason: image features have dramatically better class separation (inter-class cosine similarity ≈ -0.0014 vs text ≈ 0.668). The contrastive loss can actually distinguish classes in image space.

### 3.3 Hyperparameter Sweep — Encoder Only (COMPLETE)
25-config sweep of encoder parameters with optimal image alignment. Encoder top-1: 3.45% → 4.47% (+30%). H-mean: 4.53% → 4.54% (+0.01pp). **Key finding**: encoder is no longer the bottleneck. 30% encoder improvement → 0% H-mean improvement. The ceiling is in the synthesis pipeline.

### 3.4 Dimension Sweep — Full Pipeline (COMPLETE)
Swept embed_dim ∈ {64, 128, 256} across the full pipeline (encoder + WGAN-GP + classifier).
```
dim=64:  AccS=3.90%, AccU=5.81%, H=4.67%  ← BEST
dim=128: AccS=4.47%, AccU=4.56%, H=4.51%
dim=256: AccS=0.06%, AccU=0.00%, H=0.00%  ← CATASTROPHIC COLLAPSE
```
dim=256 collapse: 475K classifier parameters / 14,800 training samples = 32:1 ratio → massively underdetermined logistic regression. Also, concentration of measure on S^{255} makes even similar points feel far apart.
dim=64 wins: WGAN-GP hidden_dim=256 = 4× embed_dim (generous capacity ratio), classifier has ~8:1 sample-to-parameter ratio (manageable), sphere is less concentrated.
**Final optimal config**: embed_dim=64, τ=0.05, epochs=75, lr=2×10^{-3}, wd=1×10^{-4}, ImageProjector hidden=512.

### 3.5 WGAN-GP Synthesis Diagnostics (COMPLETE)
Three diagnostic tests mapping UVDS pathologies (Long et al. 2018) to our synthesis pipeline:

**Diagnostic 1 — Per-dimension variance profile**
```
VarR = mean_d( Var(ê_d) / Var(e^{real_unseen}_d) ) = 0.872
```
Synthetic embeddings have 12.8% less variance per dimension than real unseen embeddings. Mild deficit — not the primary problem.

**Diagnostic 2 — Class-conditional variance**
Synthetic per-class variance < real unseen per-class variance across all 200 classes. Same mild deficit, confirmed at class level.

**Diagnostic 3 — Neighbourhood preservation**
```
ρ(synth centroids, prototypes)        = 0.8572   [very high structural coupling]
ρ(real_unseen centroids, prototypes)  = 0.6680   [lower — real brain has more noise]
```
The synthetic class centroids are much more faithful to the prototype geometry than real unseen brain embeddings are. **This is the primary pathology**: the generator is too tightly constrained by the conditioning prototype.

### 3.6 Perturbation Sweep (COMPLETE — FAILED)

**Hypothesis**: Perturbing the conditioning prototype at synthesis time with isotropic Gaussian noise would degrade ρ(synth, proto) toward the real-unseen level (0.668) and improve H-mean.
```
s̃_c = L2_normalize(s_c + η · ξ),   ξ ~ N(0, I_{64})
```

**Results** (sweep η ∈ {0.00, 0.02, 0.05, 0.07, 0.10, 0.15, 0.20, 0.25}):
```
η=0.00: H=4.77%, AccS=4.11%, AccU=5.69%, ρ_sp=0.857, ρ_sr=0.588, VarR=0.872  ← BEST
η=0.05: H=4.08%, AccS=4.35%, AccU=3.84%, ρ_sp=0.844, ρ_sr=0.586, VarR=0.917
η=0.10: H=2.56%, AccS=4.50%, AccU=1.79%, ρ_sp=0.801, ρ_sr=0.561, VarR=1.002
η=0.25: H=0.29%, AccS=4.69%, AccU=0.15%, ρ_sp=0.570, ρ_sr=0.412, VarR=1.147
```

**Why it failed**: ρ(synth, real_unseen) DECREASED as η increased — the opposite of what should happen if the perturbation were making synthetic data more realistic. Isotropic Gaussian noise in prototype space propagates through the generator as:
```
δê ≈ J_G · (η · ξ)
```
where J_G is the generator's Jacobian with respect to the conditioning input s_c. The output perturbation lies along the COLUMNS of J_G. These columns reflect the generator's learned sensitivity directions, which have no reason to align with the actual directions of real EEG variability. We added noise in geometrically arbitrary directions — destroying the useful prototype-aligned structure without adding anything realistic.

Also: at η=0.10, VarR=1.002 (perfect variance match) but H=2.56% (much worse than η=0). Having the right AMOUNT of variance in the WRONG DIRECTIONS is worse than having slightly too little variance in the right directions.

**Key insight from this experiment**: The WGAN-GP's tight prototype coupling is a FEATURE, not a bug. The generator strips non-discriminative neural noise and produces maximally informative (clean, well-separated) synthetic embeddings. Any post-hoc degradation of this structure strictly hurts. To genuinely improve, we must modify what the generator LEARNS — not what it receives at test time.

## Section 4: Current Research Direction

**Goal**: Modify the WGAN-GP training objective so the generator learns to produce synthetic embeddings that are simultaneously:
1. Well-organised around their conditioning prototype (so the classifier can separate classes) — the current WGAN-GP already does this well
2. Have appropriate within-class diversity (to make the classifier robust to the noisier geometry of real brain embeddings at test time) — current WGAN-GP underdoes this

The fundamental tool: adding a loss term L_reg to L_G changes ∂L_G/∂θ_G. Gradient descent then adjusts the generator weights W₁, W₂, W₃ in a direction that reduces L_reg. This changes the weight matrices, which changes the Jacobian J_G = (normalisation term) · W₃ · D₂ · W₂ · D₁ · W₁^{(s)}, which changes the OUTPUT DISTRIBUTION of the generator. Training-time modifications reshape what the generator is capable of producing — unlike post-hoc perturbation which only perturbs inputs along the fixed learned manifold.

**Candidate loss modifications** (under investigation):

```
Option A — Variance Regularisation
  For each class c in a mini-batch, compute the sample covariance of generated embeddings:
    Σ̂_c = (1/K) Σ_k (ê_{c,k} - μ̂_c)(ê_{c,k} - μ̂_c)^T
  where μ̂_c = (1/K) Σ_k ê_{c,k} and K = number of samples per class in the batch

  Target: real seen per-class covariance Σ^{real}_c (precomputed from training data)

  L_var = (1/|C_batch|) Σ_c ||diag(Σ̂_c) - diag(Σ^{real}_c)||^2_2

  (diagonal only, to keep computation tractable and avoid overfitting covariance structure)

Option B — Diversity Loss
  Maximise average pairwise L2 distance within a class's generated samples:

  L_div = -(1/|C_batch|) Σ_c (2/(K(K-1))) Σ_{k<k'} ||ê_{c,k} - ê_{c,k'}||^2_2

  Adding this to L_G forces the generator to explore more of the embedding space per class.
  Gradient: pushes generated points apart from each other.

Option C — Feature Matching
  Force the statistics of intermediate generator activations to match those of real embeddings:

  L_fm = ||E_{z,c}[φ(G(z,s_c))] - E_{e~P_real}[φ(e)]||^2_2

  where φ(·) extracts intermediate layer activations from the critic D.
  This is a distributional constraint at the feature level, not just the output level.

Option D — Inter-Class Structure Preservation
  Build an affinity matrix from prototype cosine similarities:
    A_{cc'} = max(0, s_c · s_{c'})   for c ≠ c'

  Compute synthetic centroids:
    μ̂_c = (1/K) Σ_k ê_{c,k}

  Penalise if synthetic centroid distances don't match prototype distances:
    L_struct = Σ_{c,c'} ( sim(μ̂_c, μ̂_{c'}) - sim(s_c, s_{c'}) )^2
```

These are not yet implemented. Next step: derive their gradients analytically, determine which are tractable to backprop through the generator, and identify which are most likely to address the ρ mismatch without destabilising the Wasserstein objective.

## Section 6: Key Architectural Constraints to Keep in Mind

1. **All embeddings live on S^{63}**: L2-normalisation is applied at the output of f_b, g_v, and G. This means the space is a 63-dimensional manifold (sphere) embedded in R^{64}, not all of R^{64}. Distances must be interpreted as geodesic (arc length) or cosine distances, not Euclidean.

2. **Generator's output normalisation is non-differentiable at zero**: L2_normalize(u) = u / ||u||_2 has a singularity at u=0. In practice, the generator produces large-norm pre-normalised outputs, so this is not a concern.

3. **Classifier is linear**: The logistic regression learns a linear boundary in R^{64}. Nonlinear structure in the embeddings is NOT exploited by the classifier. This means the quality of the *embedding geometry* (not just the distributions) is critical.

4. **Label space**: Seen labels ∈ {1,...,1654}, unseen labels ∈ {1655,...,1854}. The label offset is applied at data loading — there is no post-hoc remapping anywhere else in the pipeline. This is important for debugging label collisions.

5. **Seen class train/test split**: 80/20 stratified split → 13,232 train, 3,308 test samples from seen data only. Unseen data (16,000 samples) is never used in training — it is the test set for unseen accuracy.

6. **Sample balancing**: Synthetic unseen data is downsampled to match seen per-class median (~8 samples/class) before training the logistic regression. Without this, the classifier routes all predictions to seen classes (97.9% routing catastrophe observed when this was dropped accidentally).
