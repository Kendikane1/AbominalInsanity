# Instructions for coding agents

Before starting work, read `PROJECT_STANDARD.md` in this directory completely.
It defines the mandatory initialization, environment, layout, reproducibility,
and verification workflow for every project beneath this directory.

When the user gives a natural-language request to start a project, follow that
standard proactively. The user should not need to remember setup commands.

If a child project contains a more-specific `AGENTS.md`, apply it in addition to
this standard, with the child instructions taking precedence for that subtree.
